ContactList→ContactsStore
Code review · Address Book · contacts feature

The contacts list hands its state to an NgRx SignalStore

The contact list kept its data, its loading flags and its search pipeline inside the component. This change moves all of it into a dedicated store and leaves the component with what belongs to the screen. Below, every moved line sits next to the line it replaced.

What changes in behaviour

=Same screen, same behaviour

Search, the A–Z filter, sorting, the selected-contact panel, keyboard navigation, delete and infinite scroll work as before. The markup is unchanged.

✓One bug fixed

After deleting a contact, scrolling down skipped one contact: it was never shown. Now no row is skipped (section 9).

iSmall clean-ups

  • Clearing an already empty search box no longer reloads the list: the state does not change, so nothing runs.
  • A leftover debug console.log is gone.
  • The page sizes 20 and 10 are named constants.

    Verification

    How this was checked

    ✓6 behaviour checks passed

    • First load: one request, 20 rows, the A–Z letters loaded.
    • Clicking a letter reloads the list; clicking it again shows everyone.
    • Typing “d”, “da”, “dan” quickly sends one request, not three.
    • Sorting keeps the selected contact; deleting it clears the selection and reloads the letters.
    • Load more after a delete asks for rows 19–28 and ends with 24 contacts: no row skipped.
    • Keyboard: ↓ selects the first row, End the last, Enter opens it, Escape clears.

    Run with Vitest (ng test) against fake services, no database. Written for this review; not in the repository yet.

    ✓Compiles cleanly

    ng build --configuration development finishes with no TypeScript or template errors. Every NgRx API used was checked against the installed @ngrx/signals 22.0.1 type definitions.

    !Outside this change

    The production ng build stops on the component style budget: contact-list.css is 9.5 kB against the 8 kB limit in angular.json. The CSS is not part of this refactor; it grew with the selected-contact panel.
